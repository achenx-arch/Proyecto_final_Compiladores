Expresiones Regulares — Categorías Léxicas

Patrones de expresiones regulares utilizados por el analizador léxico para reconocer cada categoría de token en Python. El orden de los patrones es relevante: los más específicos se evalúan primero.

# Categoría Token Expresión Regular Ejemplo Descripción
1 CADENA CADENA "[^"\n]*" "hola" Cadena con comillas dobles, sin saltos de línea
2 CADENA CADENA '[^'\n]*' 'mundo' Cadena con comillas simples, sin saltos de línea
3 COMENTARIO (ignorado) #[^\n]* # esto es un comentario Comentario de línea; descartado por el lexer
4 DECIMAL DECIMAL \d+\.\d+ 3.14 Número con punto decimal (debe evaluarse antes que ENTERO)
5 ENTERO ENTERO \d+ 42 Secuencia de uno o más dígitos
6 OPERADOR ==, !=, <=, >=, **, //, -> ==|!=|<=|>=|<<|>>|\*\*|//|-> == != <= Operadores de dos caracteres (deben preceder a los simples)
7 OPERADOR +, -, *, /, =, %, <, > [+\-*/=%<>!&|^~] + - * / Operadores aritméticos, relacionales y de asignación simples
8 DELIMITADOR ( ) { } [ ] : , . [(){}\[\]:,.] ( ) : Paréntesis, llaves, corchetes, dos puntos, coma y punto
9 IDENTIFICADOR IDENTIFICADOR / PALABRA_RESERVADA [a-zA-Z_][a-zA-Z0-9_]* nombre, if, while Inicia con letra o guión bajo; puede contener dígitos. Si coincide con keyword → PALABRA_RESERVADA
10 NUEVA_LÍNEA (control interno) \n ↵ Incrementa el contador de línea; no genera token visible
11 ESPACIO (ignorado) [ \t\r]+ ····· Espacios, tabuladores y retornos de carro; descartados
12 ERROR ERROR_LÉXICO . @ $ ` Cualquier carácter no reconocido → se registra como error léxico

Notación BNF — Gramática Formal

La Forma de Backus-Naur (BNF) define formalmente la gramática del subconjunto de Python analizado. Los símbolos entre <angulares> son no-terminales; los demás son terminales. El símbolo ε representa la producción vacía.

Gramática en BNF 
<programa>              ::= <lista_sentencias>

<lista_sentencias>      ::= <sentencia> <lista_sentencias_rest>

<lista_sentencias_rest> ::= <sentencia> <lista_sentencias_rest>
                          |  ε

<sentencia>             ::= ID <sentencia_id>
                          |  if <expresion> :
                          |  while <expresion> :
                          |  for ID in <expresion> :
                          |  def ID ( <params> ) :
                          |  return <expresion>

<sentencia_id>          ::= = <expresion>
                          |  ( <args> )

<args>                  ::= <expresion> <args_rest>
                          |  ε

<args_rest>             ::= , <expresion> <args_rest>
                          |  ε

<params>                ::= ID <params_rest>
                          |  ε

<params_rest>           ::= , ID <params_rest>
                          |  ε

<expresion>             ::= <termino> <expresion_rest>

<expresion_rest>        ::= OPERADOR <termino> <expresion_rest>
                          |  ε

<termino>               ::= ID
                          |  ENTERO
                          |  DECIMAL
                          |  CADENA
                          |  ( <expresion> )
